# Freelance Mentor

Freelance Mentor es una plataforma educativa diseñada para estudiantes universitarios. Su objetivo es proporcionarles una ruta guiada paso a paso para que puedan empaquetar sus habilidades, calcular precios justos y construir un portafolio profesional que les permita conseguir su primer cliente real.

## Estructura del Proyecto

El proyecto está organizado en las siguientes carpetas:

- **`index.html`**: Página principal de aterrizaje (Landing Page).
- **`pages/`**: Contiene páginas secundarias.
  - `auth.html`: Página de inicio de sesión y registro.
- **`css/`**: Contiene las hojas de estilo del proyecto.
  - `style.css`: Estilos principales.
  - `auth.css`: Estilos específicos para la página de autenticación.
- **`js/`**: Contiene los scripts del proyecto.
  - `script.js`: Configuración general (por ejemplo, Tailwind CSS).
  - `auth.js`: Lógica para cambiar entre inicio de sesión y registro.

## Tecnologías Utilizadas

- **HTML5** para la estructura.
- **Tailwind CSS** (vía CDN) para los estilos y utilidades rápidas.
- **JavaScript Vanilla** para interactividad simple.
- **Google Fonts** (Inter y Playfair Display) para la tipografía.

## Cómo Usar

Simplemente abre el archivo `index.html` en tu navegador web de preferencia para visualizar el proyecto. No es necesario iniciar ningún servidor local.
